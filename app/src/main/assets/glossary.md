# Glossary

## Plant Monitoring
Plant monitoring describes the continuous observation of plant conditions using sensor data such as temperature, soil moisture, light and conductivity.

## MiFlora Sensor
A Bluetooth Low Energy sensor used to measure plant-related environmental values such as soil moisture, temperature, light intensity and conductivity.

## Soil Moisture
The amount of water contained in the soil. In this project, it is used to decide whether a plant may need watering.

## Conductivity / EC
Electrical conductivity describes the amount of dissolved minerals in the soil. It is used as an indicator for fertilization.

## Light Intensity
The measured brightness around the plant, usually represented in lux.

## Reference Values
Recommended minimum and maximum values for a plant species. Sensor values are compared with these ranges.

## REST API
A web interface used by the Android app to request data from the Python backend.

## SQLite
A lightweight database used to store plant and sensor data.

## JSON
A data format used to exchange plant and sensor information between backend and Android app.

## BLE
Bluetooth Low Energy is used to communicate with plant sensors while consuming little energy.
